## Global constraints

- Plugin `demo-video`, version `1.0.0`. Agents go in `plugins/demo-video/agents/`, and each keeps its bare `name:`. Each SKILL.md `description` names the old skill ("Was the smart-screen-recorder skill"). Descriptions stay double-quoted single lines.
- **Dispatch agents by plugin agent type.** `record` names agents by file path (`~/.claude/agents/demo-storyteller.md`, and the agent table at the end). `produce` says "Launch the `product-video-storyteller` agent" with no type. Every launch instruction must name `subagent_type: "demo-video:<agent>"`. No `~/.claude/agents/` path may remain in either skill, README or agent file.
- **Every command runs as written from the user's project directory, in a fresh shell.** Same rules as #183: `"${CLAUDE_SKILL_DIR}/scripts/<name>"`, `<NAME>` placeholders for run-time values, no shell variable read in a block that did not set it, `<SCRIPTS_DIR>` in `references/*.md`. Today there are 24 findings: `record` uses `~/.claude/skills/smart-screen-recorder/scripts/...`; `produce` sets `SKILL_DIR=` in one block and reads it in others, and calls `./scripts/...` and bare `scripts/...`.
- `produce` Step 1 reads `$OPENAI_API_KEY` in `echo "${OPENAI_API_KEY:+OpenAI TTS available}" || echo "No OpenAI key found"`. The `||` branch can never run, because `echo` always succeeds. Replace it with a check that prints one of the two lines correctly and that `check-skill-commands.py` accepts.
- `references/scene-architecture.md:79` is flagged for `${interpolate(...)}`, a JS template literal. Read why the checker sees it as a command (fence language) and fix the fence label, not the checker, unless the checker is wrong.
- **Never write `${CLAUDE_SKILL_DIR}` or `${CLAUDE_PLUGIN_ROOT}` in SKILL.md prose.** `run-tests.sh` enforces this.
- **Scripts must not depend on their old install path.** `record.sh:49` and `install-deps.sh:56-57` print `~/.claude/skills/smart-screen-recorder/...`. `scaffold-project.sh:83` writes "generated by product-video-creation skill" into a `package.json`. `task-manifest.sh:8` names the old skill. Grep every script and fix each one.
- Old `plugins/smart-screen-recorder/` and `plugins/product-video-creation/` stay unchanged; they are removed in #167.
- bash 3.2 (macOS) and bash 5 (Linux): no `((n++))` under `set -e`. Python 3.9+, stdlib only in tests. No personal values or private repo names in published files.
- Commit trailer: `Co-Authored-By: <the model you are> <noreply@anthropic.com>`. Run `./scripts/commit-preflight.sh` before each commit. Stage files by name.
